# Cache hierarchy assignment references

The 2025–26 statement `advanced-ca-2025-2026-askisi2.pdf` set the coursework scope. It defined the L2 configuration sweep, IPC and miss-rate metrics, and the replacement-policy study. It was an assignment statement for designing and interpreting the experiments. Obtain the exact edition through [NTUA ECE](https://www.ece.ntua.gr/en/education/undergraduate/courses?courseId=3352) or the [CSLab course archive](https://legacy.cslab.ece.ntua.gr/courses/advcomparch/info.go).
