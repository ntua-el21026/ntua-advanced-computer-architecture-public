# Branch prediction assignment references

The 2025–26 statement `advanced-ca-2025-2026-askisi1.pdf` set the coursework scope. It defined branch-category analysis, direction prediction, BTB and RAS experiments, and the reference-input comparison. It was an assignment statement for designing and interpreting the experiments. Obtain the exact edition through [NTUA ECE](https://www.ece.ntua.gr/en/education/undergraduate/courses?courseId=3352) or the [CSLab course archive](https://legacy.cslab.ece.ntua.gr/courses/advcomparch/info.go).

The [exercise guide](../README.md) links the retained implementation record, benchmarks, and report. The statement is an external reading reference. The [separate input register](../../../EXTERNAL_INPUTS.md) covers the prerequisites for new runs.
