# Course lecture references

The twelve NTUA lecture decks supported the theoretical discussion of execution, branch prediction, cache design, synchronization, and memory systems. They were course reading and play no role in building or running the experiments. The [course listing](https://www.ece.ntua.gr/en/education/undergraduate/courses?courseId=3352) and [CSLab archive](https://legacy.cslab.ece.ntua.gr/courses/advcomparch/info.go) provide authorized entry points. Use the 2025–26 course edition for the exact set.

The [external input register](../../EXTERNAL_INPUTS.md#course-and-publisher-material) lists the original filenames. The preserved [exercise notes and reports](../../exercises/README.md) contain the student's application of the course concepts.
